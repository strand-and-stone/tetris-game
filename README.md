# Harbor Stack

Playable Tetris in the browser by **Strand & Stone**.

## Features

- Classic 10×20 Tetris with 7-bag randomizer
- Score, level, lines, next piece, ghost piece, pause
- Keyboard and touch controls
- Mobile-first UI, accessible focus states
- SEO metadata, Open Graph / Twitter cards, `robots.txt`, `sitemap.xml`

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy on Vercel

Import this repository in Vercel. No extra configuration is required — Next.js is detected automatically.

Optional: set `NEXT_PUBLIC_SITE_URL` to your production origin for absolute canonical / sitemap URLs. Without it, Vercel deployment URLs are used at build time.
